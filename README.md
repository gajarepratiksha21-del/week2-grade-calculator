# Student Grade Calculator

## Project Description

The Student Grade Calculator is a Python project created for Week 2: Control Flow & Data Structures.

The program accepts marks for multiple students, calculates their average, assigns a grade, provides personalized comments, displays class statistics, allows students to be searched, and saves results to a file.

## Features

- Add multiple students
- Enter marks for Math, Science, and English
- Calculate student averages
- Calculate grades
- Provide personalized comments
- Display results in a formatted table
- Calculate class average
- Find highest and lowest averages
- Search for a student
- Save results to a file
- Validate user input
- Handle invalid input using try-except
- Color-code grades

## Grading System

| Average | Grade | Comment |
|---------|-------|---------|
| 90-100 | A | Excellent! Keep up the great work! |
| 80-89 | B | Very Good! You're doing well. |
| 70-79 | C | Good. Room for improvement. |
| 60-69 | D | Needs Improvement. Please study more. |
| 0-59 | F | Failed. Please seek help from your teacher. |

## Python Concepts Used

### Conditional Statements

The program uses `if`, `elif`, and `else` to calculate grades.

### Lists

Lists are used to store student names, marks, and results.

### For Loops

For loops are used to process multiple students.

### While Loops

While loops are used to validate user input.

### Error Handling

`try-except` is used to handle invalid numerical input.

### Functions

Functions are used to organize the program into reusable sections.

### File Handling

The program saves student results into a text file.
